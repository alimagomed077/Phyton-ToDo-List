Python To-Do List 📝
A simple and interactive command-line To-Do List application written in Python. 
Features
Add new tasks.
Delete existing tasks by their number.
View all current tasks.
Auto-save: Tasks are saved to a tasks.json file, so your data is not lost after closing the program.
How to use
Make sure you have Python installed.
Run the script in your terminal:
   python todo.py
Follow the on-screen menu to manage your tasks.
Tech Stack
Python 3
json library for data storage
